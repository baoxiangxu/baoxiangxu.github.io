# Content

Everything the site displays lives in this folder. Editing these JSON files is
the normal way to update the site — no component code needs to change.

| File | Controls |
| --- | --- |
| `profile.json` | Name, hero line, sidebar heading, About paragraphs, contact links, SEO keywords |
| `education.json` | Education timeline |
| `publications.json` | Papers: title, coauthors, journal, year, link, abstract, figure, tags |
| `projects.json` | Project cards |
| `galleries.json` | Food / Travel gallery headings, blurbs and photo lists |
| `theme.json` | Brand colours |

Files that are replaced rather than edited (CV, downloads, paper figures) live
in `public/files/`. All source images (portrait, photos, figures) live in `originals/`.

See `编辑指南.md` in the repo root for a step-by-step guide.
